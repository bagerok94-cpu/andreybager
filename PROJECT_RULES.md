# PROJECT RULES: ANDREY BAGER

## 1. Общие принципы
1. Чистая архитектура с разделением ответственности: UI → Content Layer → API → Data Layer.
2. Никаких прямых обращений компонентов интерфейса к базе данных или внешним секретным сервисам.
3. Безопасность окружения: все приватные токены и ключи (`DATABASE_URL`, `TELEGRAM_BOT_TOKEN`) используются строго на сервере (`lib/env.ts`). Никаких утечек в клиентский бандл.
4. Отсутствие секретов в Git: файл `.env` никогда не должен попадать в репозиторий.

## 2. Стек и ограничения
- Next.js App Router с TypeScript.
- Не использовать папку `src/`.
- Не использовать Tailwind CSS, если иное явно не будет согласовано.
- Чистый, поддерживаемый TypeScript без использования `any`.

## 3. Контент и данные
- Все сущности (`PortfolioProject`, `MusicTrack`, `About`, `Service`, `Tool`, `Contact`, `SiteSettings`) типизированы в `types/content.ts`.
- Контент поставляется через слой `lib/content/`.
- Не создавать фейковые проекты в продакшн-контенте.

## 4. Визуальный стиль (запреты этапа фундамента)
- Запрещено преждевременно генерировать финальный UI без согласования концепции.
- Запрещены purple, rgb-радужные эффекты, агрессивный gaming-стиль, дешёвый glassmorphism, placeholder-изображения.
- Дизайн реализуется отдельным согласованным этапом.
