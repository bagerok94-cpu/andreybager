# AGENTS.md

Инструкции для агентов при работе над проектом ANDREY BAGER.

## Роли и специализация
При выполнении задач агенты должны руководствоваться специализированными правилами в `.agents/`:
- `.agents/design.md` — стандарты дизайн-системы и визуальных требований.
- `.agents/frontend.md` — правила разработки клиентской части, компонентов и страниц.
- `.agents/backend.md` — стандарты API, валидации данных и серверной логики.
- `.agents/database.md` — правила взаимодействия с данными и схемы PostgreSQL.
- `.agents/telegram.md` — протоколы работы с Telegram ботом и уведомлениями.
- `.agents/qa.md` — критерии тестирования, валидации сборок и приёмки кода.

## Ключевые требования к агентам
1. Перед внесением изменений всегда проверяйте текущее состояние репозитория (`git status`).
2. Не коммитить сломанный код. Перед коммитом всегда валидировать `npm run build` и линтинг.
3. Не создавать мусорных и временных файлов в корне проекта.
4. Следовать установленным соглашениям по именованию и архитектурным слоям.
